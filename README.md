# Программирование на C#

Алгоритмы, ООП и разработка приложений на C# и .NET. Здесь материалы курса по частям 1–4.

## Как работать

1. Открой папку части, например `1. Основы C#`.
2. Зайди в папку темы, например `1.1. Переменные и типы данных`.
3. Возьми презентацию по теме и изучи её вместе с преподавателем.
4. Выполни задания по теме. Каждое задание можно запустить и показать.
5. В конце части сделай проект. Он лежит в папке `Проект N. ...`.
6. Все проекты выкладывай на GitHub с README.

Темы идут по порядку, каждая опирается на предыдущую. Не переходи к следующей части, пока не получается то, что в списке «Теперь умею».
